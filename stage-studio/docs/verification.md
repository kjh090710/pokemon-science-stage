## React 훅·접근성 소스 검토

설치된 `vercel:react-best-practices` 스킬과 `client-event-listeners`, `rerender-functional-setstate`, `advanced-event-handler-refs` 규칙을 읽고 현재 React/Vite 클라이언트 흐름에 적용되는 부분을 검토했습니다. RSC/SSR 전용 규칙이나 스타일 라이브러리 변경은 이 검토 범위에 넣지 않았습니다.

- 컴포넌트의 조건부 반환 전에 훅이 선언되어 있는지 확인했습니다.
- 전역 키보드·포커스 이벤트와 타이머·채널·오디오 정리 경로를 확인했습니다. 키보드 진행은 입력창·선택창·버튼의 키 입력을 가로채지 않으며, 드래그 정렬에는 위·아래 이동 버튼도 제공합니다.
- 비동기 업로드·미리듣기·목록 조회의 이전 요청이 새 상태를 덮어쓰지 않도록 최신 문서 참조와 요청 토큰을 사용하는 흐름을 확인했습니다.
- 저장 중 재저장 요청의 Promise 대기, 편집 중 새 변경 보존, 공연 진입 전 미디어 URL 준비 상태, 체험 저장 전 문서 검증 및 실패 처리 경로를 확인했습니다.
- 인증 입력의 라벨·자동 완성, 비밀번호 표시 버튼 이름, 오류 알림, 상태 메시지를 확인했습니다.
