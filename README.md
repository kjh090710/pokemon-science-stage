# 남녕 수학과학 한마당 공연 배경

`index.html`을 브라우저에서 열고 전체 화면으로 사용합니다.

### 무료 원곡 재생

`index.html` 하단의 **무료 원곡 열기**를 누르면 `music-control.html` 조작 창이 열립니다. Windows에서 `Win + P` → **확장**을 선택하고, 조작 창은 노트북 화면에, `index.html`은 프로젝터 화면에 둡니다. 1장 암전 후 조작 창의 공식 유튜브 영상에서 재생을 누르면 무대에는 검은 화면만 보이고 노래 소리만 나옵니다. 영상이 끝나거나 다음 장면이 시작되면 조작 창에서 일시정지하세요. 이 방법은 무료지만 인터넷과 확장 화면이 필요하며, 공연 전에 현장 연결을 확인해야 합니다.

- 화면 아무 곳이나 클릭, `→`, `Space`: 다음 큐
- `←`: 이전 큐
- `B`: 긴급 암전
- `F`: 전체 화면
- `O`: 진행 메모
- `M`: 연결한 노래 재생 또는 일시정지
- `S`: 노래를 수동으로 다시 시작
- `C`: 하단 조작 바 표시 또는 숨김 (공연 중에는 기본으로 숨김)
- `U`: 무료 원곡 조작 창 열기

대사 중 같은 배경을 쓰는 구간은 한 장면으로 합쳤습니다. 1장의 UV 암전 중에는 로켓단 퇴장 뒤 `S` 키로 노래를 시작합니다. 준비가 끝나면 클릭 한 번으로 2장 관문 배경이 나옵니다.

투사 화면에는 대본 문구나 퀴즈 질문을 표시하지 않습니다. 장면 배경과 암전만 보이며, 문이 열리는 큐에서는 관문 전체가 아니라 가운데 문짝만 움직입니다. 암전 큐에서는 노래 파일을 연결했다면 재생됩니다. 운영 메모는 `O` 키를 눌렀을 때만 표시되므로 공연 전에 닫아 주세요.

10월 22일 수정 대본에 맞춰, 1장은 박사님 연구실에서 시작합니다. 지우와 웅이가 퇴장하고 로켓단이 등장할 때 클릭하면 마을 배경으로 바뀝니다. 갑자기 불이 꺼질 때 다시 클릭하면 검은 화면과 무음으로 바뀌고, 배우가 UV 손전등으로 실제 칠판의 “호수” 단서를 보여줍니다. 로켓단 퇴장 후 `S` 키로 검은 화면에서 노래 소리만 시작하고, 2장 세팅이 끝나면 클릭 한 번으로 관문 배경으로 넘어갑니다.

연구실은 원본을 참고해 선명하게 보강했고, 마을·바다·호수는 배우 눈높이에서 보이도록 새로 제작했습니다. 무대에 쓰는 PNG는 1920×1080으로 저장했으며 생성 기준 해상도는 1672×941입니다. 관문 PNG는 1672×941입니다. 4장의 호수는 처음부터 주변 풍경을 약간 차분하게 보여줍니다. 아이오딘을 붓는 큐에서 물에는 검은 마스크가 씌워지고 하늘·산·풀밭도 함께 어두워집니다. 비타민 C 큐에서는 모두 원래 밝기로 돌아옵니다. 이전 배경은 별도 파일로 보존했습니다. 「우리는 모두 친구」 MP3 파일을 `audio/우리는 모두 친구.mp3`에 넣으면 자동으로 찾습니다. 현재 음원 파일이 없으므로 재생하려면 `C` 키로 조작 바를 열어 **노래 파일 연결**에서 직접 선택해야 합니다.
