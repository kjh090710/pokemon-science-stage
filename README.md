# 남녕 수학과학 한마당 공연 배경

배포 주소: https://kjh090710.github.io/pokemon-science-stage/

`index.html`을 브라우저에서 열어 빔 프로젝터에 전체 화면으로 띄웁니다. 2026년 10월 22일 전달받은 `앰배수정하자 (1).pdf`의 PPT 번호와 무대 지시에 맞춘 화면입니다. 배우의 대사, 안내문, 퀴즈 문제는 투사하지 않습니다.

## 조작

- 화면 클릭, `→`, `Space`: 다음 큐. 한 번 누르면 한 큐만 이동합니다.
- `←`: 이전 큐. `B`: 긴급 암전. `F`: 전체 화면.
- `O`: 운영 메모. `C`: 하단 조작 바 표시 또는 숨김. 공연 화면에서는 기본으로 숨깁니다.
- `S`: 연결한 「우리는 모두 친구」 음원 시작. `M`: 음악 재생 또는 일시정지.
- `U`: 별도 음악 조작 창 열기. 이 창은 노트북 화면에만 두고 빔에는 공연 화면을 둡니다.

## 음악

현재 배포본에는 저작권이 있는 노래 파일이 포함되어 있지 않습니다. `audio/우리는 모두 친구.mp3`를 로컬 폴더에 넣거나 조작 바의 **노래 파일 연결**로 선택하면 `S` 키로 재생할 수 있습니다. 웹에 배포된 화면은 로컬 폴더의 MP3를 자동으로 읽지 못하므로 파일 선택을 사용하세요. 「route 216」과 「Farewell」, 문 열림 효과음도 별도 음원으로 공연 장비에서 재생해야 합니다. 브라우저는 사용자 동작 없이 소리 자동 재생을 제한할 수 있어 공연 전 현장 리허설에서 확인하세요.
