# 남녕 수학과학 한마당 공연 배경

[공연 화면](https://kjh090710.github.io/pokemon-science-stage/) · [제어창](https://kjh090710.github.io/pokemon-science-stage/control.html)

2026년 10월 22일 마지막으로 전달받은 대본의 PPT 1–18 및 퀴즈 무대 지시를 기준으로 확인했습니다. 배우의 대사와 퀴즈 문제는 공연 화면에 표시하지 않습니다. 사용자가 제공한 메타몽·꼬부기 지시문 이미지 두 장은 대본의 PPT 4·8에서 원래 비율을 유지해 오른쪽 정렬로 표시합니다.

## 진행

- 같은 브라우저에서 제어창과 공연 화면을 열고, 공연 화면을 빔 프로젝터에 배치해 `F`로 전체 화면을 만듭니다.
- 첫 화면은 개막 대기 암전입니다. 큰 버튼의 **우리는 모두 친구 · 가사 있음 재생**을 눌러 공연을 시작합니다. 개막곡이 끝나면 **개막곡 종료 · 연구실로**를 누르고 현장 조명을 켭니다.
- 상단 **음향 접기 / 음향 펼치기**로 음향 패널을 숨길 수 있습니다. 접으면 미리보기가 넓어지고 재생은 계속됩니다. 펼침 상태도 이 브라우저에 저장됩니다.
- **음향 펼치기**에서 5개 음원의 **개별 음량**을 각각 0–100%로 지정할 수 있습니다. 재생 중에도 즉시 적용되며 자동 재생과 수동 재생 모두 같은 설정을 사용합니다. 각 값은 이 브라우저에 저장됩니다. 전체 볼륨은 공통으로 곱해집니다(예: 전체 75% × 개별 50% = 약 37.5%). 음악 페이드와 문 효과음의 4초 길이는 독립적으로 유지됩니다.
- 큰 버튼에는 다음 동작이 표시됩니다. 음악만 시작·종료하는 단계에서는 배경이 유지됩니다. 별도 재생·일시정지·서서히 정지·볼륨 조작은 비상 및 리허설용으로 그대로 남아 있습니다.
- UV 단서 암전에서 로켓단 퇴장 후 다음 버튼으로 반주를 시작합니다. 다음 관문 앞 단계에서 음악이 서서히 종료됩니다.
- 웅이가 지시문을 펼치면 **메타몽 지시문 보기** 또는 **꼬부기 지시문 보기**를 누릅니다. 읽기가 끝나면 **지시문 닫기 · 관문으로 / 바다로**를 눌러 실제 실험 전에 장소 배경으로 돌아갑니다.
- 비타민 C로 호수를 정화 → **Farewell 재생 · 뮤 등장** → 뮤가 끄덕이면 **Farewell 종료** → 지우가 도감 완성을 말한 뒤 **암전 · 우리는 모두 친구 반주 재생** 순서입니다.
- 공연 화면 클릭·`→`·`Space`로 넘겨도 열려 있는 제어창이 음향을 따라갑니다. 음향 사용을 위해 제어창에서 한 번 조작해 브라우저 재생을 허용하세요. 제어창이 없으면 화면만 진행됩니다.
- `←`는 이전, `B`는 긴급 암전입니다. 긴급 암전은 재생 중 효과음을 멈추고 음악을 서서히 줄입니다. 실제 무대 조명은 연출팀이 제어창 메모에 따라 조작합니다.

## 대본 대조 후 수정

- PPT 4의 메타몽 지시문과 PPT 8의 꼬부기 지시문은 제공된 원본 이미지를 표시합니다. 읽은 뒤에는 각각 관문·바다로 돌아가며, 화학 반응 실험의 암전 순서는 유지합니다.
- 첫 실험(PPT 9)의 초록빛은 플루오레세인, 두 번째 실험(PPT 11)의 파란빛은 루미놀로 운영 메모를 바로잡았습니다.
- PPT 15에서는 검은 호수를 유지하면서 전면 두 줄 조명 OFF → 백만 볼트 점멸·돌진 → 전체 조명 ON 순서를 메모에 추가했습니다.
- Farewell은 뮤가 고개를 끄덕일 때 음악만 끕니다. 지우의 도감 완성 대사까지 호수를 유지한 다음 PPT 17 암전으로 넘어갑니다.
- 개막곡·1장 후 반주·Farewell 재생과 종료가 진행 버튼 안에 포함됩니다. 음악은 약 0.9초 동안 서서히 커지고, 기본 2.5초 동안 서서히 작아집니다. 제어창의 페이드아웃 시간 슬라이더로 0.5–8초 사이를 조절할 수 있으며 설정은 이 브라우저에 저장됩니다. 끝까지 재생한 곡도 같은 길이로 페이드아웃됩니다. 페이드는 현재 설정된 재생 음량을 100% 기준으로 삼아 0까지 연속적으로 줄이며, 개별·전체 볼륨을 별도로 유지합니다. 페이드인·페이드아웃 도중 다른 동작을 눌러도 그 순간 음량에서 이어집니다.

2장의 장소 배경은 입장부터 실험·포획까지 같은 닫힌 관문으로 통일했습니다. 지시문 뒤에도 같은 관문으로 돌아오며 포획 이후에만 문이 열립니다.

5장 연구실 귀환부터 가사 있는 「우리는 모두 친구」를 기본 개별 음량 25%로 무한 반복합니다. 음향창의 **5장 이후 · 우리는 모두 친구 반복** 음량은 개막곡과 별도로 조절·저장됩니다. 커튼콜·퀴즈·최종 암전으로 넘어가도 곡이 처음부터 재시작되지 않습니다. 수동 정지·일시정지·긴급 암전을 하면 다음 장면에서도 정지 상태를 유지하며, 반복 재생 버튼으로 다시 시작할 수 있습니다. 공연 종료 때 **서서히 정지**를 누릅니다.

## 문과 효과음

사용자가 제공한 15.36초 원본에서 처음 4초를 골라 속도를 유지한 짧은 효과음 `audio/door-open-short.mp3`를 제작했습니다. 시작 50ms·끝 180ms 페이드와 음량 정리를 적용했습니다. 원본 파일도 보관합니다.

문은 서서히 반쯤 열리는 4초 동작입니다. 제어창이 효과음을 준비한 뒤 공통 시작 시각을 공연 화면에 전달하고, Web Audio 시계로 효과음을 예약합니다. 문 동작의 마지막 시점과 효과음 종료 시점은 같은 4초 기준입니다. 문 동작 도중 다음 단계로 넘기거나 긴급 암전을 하면 효과음도 즉시 중단됩니다. 음악 페이드와 사용자가 조절하는 전체 볼륨은 별도로 적용됩니다.

## 기본 음원과 배경

「우리는 모두 친구」 두 버전, Route 216, Farewell, 문 효과음은 기본 연결되어 있습니다. 가사 없는 버전은 사용자가 제공한 「포켓몬스터 OST - 엔딩 노래(우리는 모두 친구) 피아노 커버.mp3」에서 앞부분 무음 2.755초만 제거한 파일을 사용합니다. 첫 음 앞에 약 20ms 여유를 남겨 연주 시작을 보존했고, 이 반주의 시작 페이드는 20ms로 줄였습니다. 1장 후·4장 후 반주와 제어창의 가사 없음 재생 버튼에 같은 피아노 커버 음원이 적용됩니다. 직접 선택한 교체 파일은 서버로 업로드되지 않으며 새로고침하면 다시 선택해야 합니다.

연구실·숲·바다·호수는 현장 시점의 배경입니다. 기본 호수와 정화된 호수는 흰빛을 더한 연분홍색, 먹구름 장면은 물과 주변 풍경이 함께 어두워진 별도 이미지입니다. 마지막 귀환과 퀴즈 1–3번은 연구실, 퀴즈 4번 플라즈마볼 실험은 완전 암전입니다. 공연 화면의 마우스와 조작 바는 기본 숨김입니다.
