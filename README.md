# 남녕 수학과학 한마당 공연 배경

배포 주소: https://kjh090710.github.io/pokemon-science-stage/
제어창: https://kjh090710.github.io/pokemon-science-stage/control.html

`index.html`을 빔 프로젝터에 전체 화면으로 띄우고, `control.html`을 노트북 화면에 엽니다. 두 페이지는 같은 브라우저의 같은 웹 주소에서 열어야 장면 조작이 연결됩니다. 2026년 10월 22일 전달받은 `앰배수정하자 (1).pdf`의 PPT 번호와 무대 지시에 맞춘 화면입니다. 배우의 대사, 안내문, 퀴즈 문제는 투사하지 않습니다.

## 조작

- 제어창의 **다음 장면**을 한 번 클릭하면 다음 큐로 이동합니다. **이전**, **긴급 암전**, 큐 목록의 직접 이동도 가능합니다.
- 제어창에서 다섯 음원 파일을 각각 선택한 뒤 재생합니다. 문 열림 효과음과 장 사이 음악은 제어창에서 해당 큐로 이동할 때 자동으로 시작합니다.
- 공연 화면은 조작 바와 마우스 포인터가 기본으로 숨겨집니다. 공연 화면에서 `F`를 눌러 전체 화면으로 만드세요.
- 연결이 끊기거나 제어창을 닫았을 때 공연 화면 클릭, `→`, `Space`는 다음 큐, `←`는 이전 큐, `B`는 긴급 암전입니다.

## 음악

현재 배포본에는 저작권이 있는 음원 파일이 포함되어 있지 않습니다. `control.html`에서 가사 있는 「우리는 모두 친구」, 가사 없는 버전, 「route 216」, 「Farewell」, 문 열림 효과음을 각각 선택하세요. 선택한 파일은 노트북 브라우저에서만 열리며 서버로 업로드되지 않습니다. 개막곡과 1장 후 반주, 「Farewell」은 배우 대사에 맞춰 제어창에서 직접 재생합니다. 문 효과음과 2·3·4장 후 음악은 해당 큐로 넘길 때 자동 시작합니다. 무료 원곡용 `music-control.html`은 제어창 하단 링크로 열 수 있습니다. 브라우저를 새로고침하면 음원을 다시 선택해야 하므로 공연 전 현장 리허설에서 연결과 소리 출력을 확인하세요.
